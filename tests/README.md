# Testing and Evaluation

This folder contains screenshots showing the testing and evaluation of the Hospital Patient Readmission Risk Prediction project.

## Screenshots

1. `logistic_regression_confusion_matrix.png` – Confusion matrix of Logistic Regression.
2. `decision_tree_confusion_matrix.png` – Confusion matrix of Decision Tree.
3. `streamlit_app_colab_preview.png` – Preview of the Streamlit application.
4. `streamlit_prediction_results.png` – Prediction results generated by the application.
5. `streamlit_prediction_table.png` – Patient readmission prediction table.
6. `precision_recall_curves.png` – Precision-recall evaluation curves.
7. `classification_reports.png` – Classification reports of the trained models.
8. `model_performance_comparison.png` – Comparison of model performance.

## Evaluation Metrics

The machine learning models were evaluated using:

- Accuracy
- Precision
- Recall
- F1-score
- ROC-AUC

The screenshots provide visual evidence of model evaluation and application testing.
