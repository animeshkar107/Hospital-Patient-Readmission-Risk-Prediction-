# Source Code

This folder contains reusable Python source code for the Hospital Patient Readmission Risk Prediction project.

The project uses machine learning algorithms to classify hospital encounters based on 30-day readmission status.

## Main Components

- Data preprocessing
- Feature transformation
- Machine learning model training
- Model evaluation
- Prediction generation

The main Streamlit application is available in the root directory as `app.py`.

The trained model pipeline is saved as `readmission_model.pkl`.
