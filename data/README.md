# Dataset Information

## Dataset Name
Diabetes 130-US Hospitals for Years 1999–2008

## Source
UCI Machine Learning Repository

## Dataset Link
https://archive.ics.uci.edu/dataset/296/diabetes+130+us+hospitals+for+years+1999-2008

## Description
The dataset contains hospital records of diabetic patients from 130 US hospitals between 1999 and 2008.

It includes patient demographics, admission details, diagnoses, medications, and readmission information.

## Target Variable
The original `readmitted` column contains:
- NO
- >30
- <30

For this project, early readmission (`<30`) is treated as the positive class.

## Note
The original dataset is not included in this repository. Users can download it from the UCI Machine Learning Repository.
