# Hospital Patient Readmission Risk Prediction

## 1. Project Overview
This project uses Machine Learning to predict the risk of early hospital readmission among diabetic patients. It uses patient records from the Diabetes 130-US Hospitals dataset.

## 2. Business Problem
Hospital readmissions can increase healthcare costs and affect patient care. Identifying patients at risk of early readmission can help healthcare providers plan better follow-up care.

## 3. Project Objectives
- Analyze hospital patient data.
- Preprocess and prepare data for machine learning.
- Build and compare classification models.
- Predict early readmission risk.
- Develop a Streamlit application for predictions.

## 4. Dataset
**Dataset:** Diabetes 130-US Hospitals for Years 1999–2008

**Source:** UCI Machine Learning Repository

https://archive.ics.uci.edu/dataset/296/diabetes+130+us+hospitals+for+years+1999-2008

## 5. Technologies Used
- Python
- Google Colab
- Pandas and NumPy
- Scikit-learn
- Matplotlib and Seaborn
- Streamlit
- Joblib

## 6. Machine Learning Models
- Logistic Regression
- Decision Tree
- Random Forest

## 7. Project Structure
- `notebook/` – Google Colab notebook containing data preprocessing, model training and evaluation.
- `report/` – Final project report.
- `data/` – Dataset information and download instructions.

## 8. Model Evaluation
The models are evaluated using:
- Accuracy
- Precision
- Recall
- F1-score
- ROC-AUC

## 9. Limitations
This project is an academic machine learning prototype. Its predictions are not intended for clinical decision-making.
